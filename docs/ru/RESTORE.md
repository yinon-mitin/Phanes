# Восстановление и откат Phanes

[English](../RESTORE.md) · [Русский](RESTORE.md)

## 1. Подготовка хоста

Установите Git, Docker Engine/Desktop с Compose v2, Make и Python 3. Проверьте доступность registry, указанных в `stack/versions.env`.

## 2. Локальная конфигурация

```sh
make init
# Отредактируйте stack/.env: абсолютные пути, UID/GID, часовой пояс и новый ключ Homarr.
make test
```

Не используйте ключи из истории Git. Файл `stack/.env` не должен отслеживаться.

## 3. Чистый запуск

```sh
make pull
make up
make ps
```

Настройте приложения в следующем порядке:

1. qBittorrent
2. Prowlarr и/или Jackett
3. Sonarr и Radarr
4. Bazarr и Recyclarr
5. Jellyfin
6. Jellyseerr и Aperture
7. Homarr и опциональные сервисы

Во всех контейнерах используйте единый путь `/media`, чтобы import и hardlink не ломались из-за разных путей.

## 4. Восстановление состояния

Остановите сборку, восстановите зашифрованный snapshot `APPDATA_ROOT` и проверьте владельца файлов относительно `PUID` и `PGID`.

```sh
make up
make verify
```

Не копируйте активные SQLite-базы без согласованного snapshot файловой системы. Используйте встроенный backup приложения или сначала остановите соответствующие контейнеры.

## 5. Откат

Вернитесь к предыдущей ревизии Git и восстановите совместимый snapshot `APPDATA_ROOT`. Запуск старого контейнера поверх базы, мигрированной новой версией, не считается безопасным откатом.

# Воспроизводимость Phanes

[English](../REPRODUCIBILITY.md) · [Русский](REPRODUCIBILITY.md)

Релиз считается воспроизводимым, если одинаковая ревизия Git и одинаковые локальные входные данные создают одну и ту же топологию Compose и те же ссылки на OCI-образы.

## Закреплённые входные данные

- Все 17 образов закреплены в `stack/versions.env`.
- Шестнадцать образов имеют manifests для amd64 и arm64; Aperture явно ограничен `linux/amd64`.
- Compose не выбирает плавающие версии.
- `stack/.env.example` описывает локальные параметры без настоящих секретов.
- Активный образ Aperture закреплён digest. Его опциональный исходный код закреплён ревизией Git и patch-файлом.
- Рабочие базы и каталог медиатеки не являются входными данными Git.

## Проверка

```sh
make test ENV_FILE=stack/.env.example
```

Проверка отклоняет плавающие ссылки на образы, отсутствующие переменные, незакреплённые digest, неожиданные сервисы, запрещённые рабочие файлы и некорректный Compose.

## Обновление образов

```sh
make update-lock
make test ENV_FILE=stack/.env.example
git diff -- stack/versions.env
```

Проверьте changelog каждого сервиса. Сначала протестируйте новый lock-файл на временных данных, затем на копии рабочего состояния.

## Ограничения

Digest закрепляет OCI-артефакт, но не CPU, kernel, Docker Engine, поведение файловой системы или внешние API. Перед production-развёртыванием проверьте целевую архитектуру и зафиксируйте версию Docker/Compose.

Jellyfin Intro Skipper Docker Mod исключён: его registry не разрешил анонимно получить digest. Мод нельзя возвращать в базовую сборку без immutable-ссылки.

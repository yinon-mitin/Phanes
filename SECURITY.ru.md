# Политика безопасности

[English](SECURITY.md) · [Русский](SECURITY.ru.md)

## Сообщение об уязвимости

Не публикуйте в issue учётные данные, адреса серверов, названия медиа, логи, фрагменты баз или screenshots с личной информацией. Передавайте такие отчёты владельцу репозитория по согласованному приватному каналу.

## Границы репозитория

В Git хранятся только воспроизводимая инфраструктура и безопасные шаблоны. Рабочее состояние находится в `APPDATA_ROOT`, медиатека — в `MEDIA_ROOT`, секреты — в `stack/.env` или secret manager.

Если секрет попал в commit, удаление файла следующим commit не устраняет утечку. Немедленно замените credential и перепишите историю до распространения репозитория.

## Развёртывание

- Храните рабочее состояние, credentials и чувствительные сведения об инфраструктуре приватно; сам репозиторий является публичным.
- Проверяйте обновления lock-файла перед запуском.
- Создавайте backup состояния перед обновлением контейнеров.
- Не публикуйте сервисные порты в Internet без TLS, аутентификации и явной сетевой политики.
- Монтируйте Docker socket только в `docker-socket-proxy`; Homarr должен использовать внутренний proxy с `POST=0`, а proxy не должен публиковать host-порт.
- Публикуйте управляющие HTTP-порты только через gateway, привязанные к указанным LAN и Tailscale интерфейсам.
